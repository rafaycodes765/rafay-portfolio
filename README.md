# 📲 Barcode Menu Reader

A smart, Python-powered desktop application that allows restaurants to **generate** and **scan QR codes** for digital menus — all in one place. This contactless solution improves customer experience while reducing physical interaction.

---

## 🚀 Features
- 🔳 Generate QR Codes for complete restaurant menu
- 📷 Scan QR Codes using webcam and decode menu instantly
- 🧾 Display Menu in App (with category-wise breakdown)
- 🌐 Generate HTML Page of menu for browser view
